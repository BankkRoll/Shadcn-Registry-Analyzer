# Shadcn Registry Analyzer

A **universal, professional-grade analyzer and visualizer** for any [shadcn/ui](https://ui.shadcn.com) registry or compatible registry.

Analyze, preview, and install any component, style, theme, or block—**from any registry, URL, or install command**—with a modern UI.

---

## 🚀 Getting Started

1. **Install dependencies:**
   ```sh
   npm install
   # or
   yarn install
   # or
   pnpm install
   # or
   bun install
   ```

2. **Start the dev server:**
   ```sh
   npm run dev
   # or yarn dev, pnpm dev, bun dev
   ```

3. **Open [http://localhost:3000](http://localhost:3000) in your browser.**

4. **Analyze any registry item:**
   - Paste a registry URL, install command, or name into the input.
   - Instantly see all files, dependencies, install commands, and live previews.

---

## Extensibility

- **Supports all registry types:**
  Components, styles, themes, blocks, utilities, and more.
- **Handles any file type:**
  TypeScript, JavaScript, CSS, JSON, config, etc.
- **Easy to extend:**
  Add custom file previews, new registry types, or new install command formats.
